# Hodíe

Hodíe is a today-first productivity app for iOS and macOS. It combines capture, planning, calendar context, focus sessions, and daily review into one calm Apple-native workflow so people can run their entire day without juggling multiple tools.

## Highlights
- Tasks, calendar context, planning, focus timer, and daily review live in one SwiftUI experience.
- Apple-first: only iOS and macOS targets are in scope for the MVP (shared SwiftUI views + SwiftData).
- Local-first data model so the app feels fast and works offline; sync will come later.
- Opinionated workflow that favors clarity over knobs, while still accommodating humane rescheduling.
- Long-term personalization goal: after the core workflow ships, a first-launch questionnaire will tailor the app to the productivity systems that fit each user best.

## Current Status
- Project skeleton generated by Xcode with a shared SwiftUI scene for iOS + macOS.
- `Item` SwiftData model stores placeholder entries so the navigation shell and persistence flow can be exercised.
- Planning, calendar integration, focus timer, and review experiences are defined in `docs/Hodie_PLAN.md` and are next on the roadmap.

## Requirements
- macOS Sonoma (or newer) with the latest Xcode 15.x installation.
- Swift 5 toolchain (project currently compiles with `SWIFT_VERSION = 5.0`).
- iOS / iPadOS simulator or device on current OS releases, or macOS target for the desktop build.

## Getting Started
1. Clone the repo and install dependencies (none required beyond Xcode):
   ```bash
   git clone https://github.com/misavoid/hodie.git
   cd hodie
   ```
2. Open the project in Xcode: `open Hodie.xcodeproj` (or `xed .`).
3. Choose the `Hodie` scheme.
4. Select either the iOS Simulator or the macOS destination.
5. Build & run with `Cmd+R`.

### Running Tests
- Press `Cmd+U` inside Xcode to run `HodieTests` and `HodieUITests`.
- Tests currently cover template scaffolding; more meaningful coverage will arrive with real features.

## Project Structure
- `Hodie/` – shared app target with SwiftUI scenes (`HodieApp.swift`, `ContentView.swift`), SwiftData models, assets, and entitlements.
- `HodieTests/` – unit tests (placeholder generated by Xcode).
- `HodieUITests/` – UI tests (placeholder).
- `docs/` – product and technical planning docs (`Hodie_PLAN.md` is the central reference).
- `AGENTS.md` – guidelines for contributors and the foundational product brief.

## Roadmap Snapshot
The MVP focuses on six pillars (see `docs/Hodie_PLAN.md` for the full brief):
1. Task capture inbox.
2. Today view with scheduled + unscheduled work plus calendar context.
3. Task management (create/edit/complete/delete, lightweight states).
4. Planning flow to slot tasks into the day and optionally into time blocks.
5. Focus timer linked directly to tasks (pomodoro-style sessions with history).
6. End-of-day review and rollover for unfinished tasks.

## Contributing
- Keep changes aligned with the Apple-only scope and the “plan the day, run the day” north star.
- Favor straightforward SwiftUI + SwiftData solutions over heavy abstractions.
- When in doubt, consult `AGENTS.md` and `docs/Hodie_PLAN.md` for priorities and decision rules.
- Document new workflows in `docs/` as they evolve.
